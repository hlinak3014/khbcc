# KHBCC 웹사이트

한국–헝가리 배터리 협력 연구센터(KHBCC) 웹사이트입니다.
한국어·영어·헝가리어 3개 국어로 운영합니다.

---

## 담당자용 — 새 소식 올리기

주소창에 사이트 주소 뒤에 `/admin` 을 붙여 들어갑니다.

```
hlinak3014.github.io/khbcc/admin
```

로그인하면 편집 화면이 나옵니다. 왼쪽에서 **활동 기록**을 누르고,
아래쪽 **소식 추가** 버튼을 누른 뒤 칸을 채우면 됩니다.

- **날짜** — 이 값으로 연도가 나뉘고 순서가 정해집니다
- **장소** — 비워도 됩니다
- **사진** — 끌어다 놓으면 올라갑니다. 없으면 비워둡니다
- **관련 링크** — 기사 주소가 있을 때만. `https://` 로 시작해야 합니다
- **한국어 / English / Magyar** — 세 칸 모두 채웁니다

오른쪽 위 **Publish** 를 누르면 저장됩니다. 1~2분 뒤 사이트에 나타납니다.

기존 소식을 고칠 때도 같은 화면에서 해당 항목을 펼쳐 수정하면 됩니다.

### 주의

- 세 언어를 모두 채워 주세요. 한 칸이라도 비면 해당 언어 사용자에게 빈 항목으로 보입니다.
- 사진 파일 이름은 자동으로 처리되니 신경 쓰지 않아도 됩니다.
- 잘못 저장했더라도 이전 내용이 GitHub에 남아 있어 되돌릴 수 있습니다.

## 관리자용 — 편집 화면 최초 설정

편집 화면은 DecapBridge라는 인증 서비스를 씁니다. 처음 한 번만 설정하면 됩니다.

1. https://decapbridge.com 에서 가입합니다. (무료 — 사이트 3개, 협업자 10명)
2. 사이트를 새로 만들고 `hlinak3014/khbcc` 저장소를 연결합니다.
3. DecapBridge가 만들어주는 `config.yml` 내용을 복사합니다.
4. 이 저장소의 `admin/config.yml` 을 열어 맨 위 `backend:` 부분을 그 내용으로 바꿉니다.
5. 저장하면 `/admin` 에서 로그인이 됩니다.

이후 편집자를 추가할 때는 DecapBridge 화면에서 이메일로 초대하면 됩니다.
초대받은 사람은 GitHub 계정 없이 이메일과 비밀번호로 로그인합니다.

### 참고

- 글과 사진은 모두 GitHub 저장소에 저장됩니다. DecapBridge는 로그인만 처리합니다.
  이 서비스에 문제가 생겨도 사이트와 데이터는 그대로 남습니다.
- 도메인(`khbcc.org`)을 붙일 때 이 설정을 고칠 필요는 없습니다.
  단, DecapBridge 사이트 설정의 주소만 새 도메인으로 바꿔주세요.

## 파일 구성

```
index.html        메인 페이지 (한국어 문구가 여기 들어 있음)
news.html         활동 기록 페이지 (틀만 있음)
news.json         ★ 활동 기록 내용. 편집 화면이 이 파일을 고칩니다
i18n.js           영어·헝가리어 번역문
admin/            편집 화면
  index.html
  config.yml      ★ 편집 화면 설정
assets/           로고 이미지
assets/news/      활동 기록 사진
```

## 문구 고치기 (개발자용)

메인 페이지 문구는 편집 화면에 넣지 않았습니다.
3개 언어가 함께 바뀌어야 하는데 한 언어만 고쳐지면 내용이 어긋나기 때문입니다.

- 한국어: `index.html` 에서 해당 글자를 찾아 고칩니다
- 영어·헝가리어: `i18n.js` 에서 같은 이름(`heroTitle` 등)을 찾아 따옴표 안만 고칩니다
- `data-i18n="..."` 부분과 태그는 건드리지 마세요
