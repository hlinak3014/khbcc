# KHBCC 웹사이트

한국–헝가리 배터리 협력 연구센터(KHBCC) 웹사이트입니다.
한국어·영어·헝가리어 3개 국어로 운영합니다.

---

## 관리자 화면

사이트 주소 뒤에 `/admin` 을 붙여 들어갑니다.

```
hlinak3014.github.io/khbcc/admin
```

**현재는 미리보기 모드입니다.** 로그인 없이 바로 편집 화면이 뜨고 기존 활동 기록 16건도
그대로 보이지만, **수정한 내용은 저장되지 않습니다.** 화면 구성을 확인하고 보여드리기 위한
상태입니다. 상단에 빨간 표시가 나옵니다.

### 화면 언어

오른쪽 위 **KO / HU / EN** 버튼으로 편집 화면 자체의 언어를 바꿉니다.
메뉴, 입력 칸 이름, 목록의 제목이 모두 해당 언어로 바뀝니다.
기본값은 영어이며, `admin/index.html` 의 `DEFAULT_UI_LANG` 에서 변경할 수 있습니다.

### 화면 사용법

왼쪽에서 **활동 기록**을 누르고, **소식 추가** 버튼을 누른 뒤 칸을 채웁니다.

- **날짜** — 이 값으로 연도가 나뉘고 순서가 정해집니다
- **장소** — 비워도 됩니다
- **사진** — 끌어다 놓으면 올라갑니다. 없으면 비워둡니다
- **관련 링크** — 기사 주소가 있을 때만. `https://` 로 시작해야 합니다
- **한국어 / Magyar / English** — 세 칸 모두 채웁니다

### 실제로 저장되게 하려면

1. <https://decapbridge.com> 가입 (무료 — 사이트 3개, 협업자 10명)
2. 사이트를 만들고 `hlinak3014/khbcc` 저장소를 연결
3. DecapBridge가 알려주는 값으로 `admin/config.yml` 의 `backend:` 부분을 교체
4. `admin/index.html` 에서 `var USE_REAL = false;` 를 `true` 로 변경

이후 편집자를 추가할 때는 DecapBridge 화면에서 이메일로 초대합니다.
초대받은 사람은 GitHub 계정 없이 이메일과 비밀번호로 로그인합니다.

글과 사진은 모두 GitHub 저장소에 저장됩니다. DecapBridge는 로그인만 처리하므로,
이 서비스에 문제가 생겨도 사이트와 데이터는 그대로 남습니다.

## 문구 고치기 (개발자용)

메인 페이지 문구는 편집 화면에 넣지 않았습니다.
3개 언어가 함께 바뀌어야 하는데 한 언어만 고쳐지면 내용이 어긋나기 때문입니다.

- 한국어: `index.html` 에서 해당 글자를 찾아 고칩니다
- 영어·헝가리어: `i18n.js` 에서 같은 이름(`heroTitle` 등)을 찾아 따옴표 안만 고칩니다
- `data-i18n="..."` 부분과 태그는 건드리지 마세요

## 첫 화면 사진 슬라이드

메인 페이지 오른쪽 사진은 **활동 기록에서 자동으로 가져옵니다.**
사진이 있는 최근 항목 6개가 12초마다 순환하며, 날짜와 제목도 함께 바뀝니다.

활동 기록에 새 소식을 사진과 함께 올리면 첫 화면에도 자동으로 나타납니다.
따로 손댈 것이 없습니다.

바꾸려면 `index.html` 맨 아래 스크립트에서 두 값을 고칩니다.

```
var INTERVAL = 12000;   // 바뀌는 간격 (12000 = 12초)
var MAX = 6;            // 순환할 사진 개수
```

## 활동 기록의 장소 이름

`news.json` 의 장소는 한국어로 한 번만 적습니다.
영어·헝가리어 표기는 `i18n.js` 맨 아래 `PLACES` 에서 관리합니다.

새로운 장소를 쓰면 거기에도 한 줄씩 추가하세요.
없으면 그 언어에서도 한국어가 그대로 나옵니다.
