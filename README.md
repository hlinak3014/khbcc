# KHBCC 웹사이트

한국–헝가리 배터리 협력 연구센터(KHBCC) 웹사이트입니다.
한국어·영어·헝가리어 3개 국어로 운영합니다.

## 파일 구성

```
index.html        메인 페이지
news.html         활동 기록 페이지 (틀만 있음. 내용은 news-data.js에서 가져옴)
news-data.js      ★ 활동 기록 내용. 새 소식을 추가할 때 여기만 고칩니다
i18n.js           영어·헝가리어 번역문. 문구를 고칠 때 여기를 봅니다
assets/           로고 이미지
assets/news/      활동 기록에 넣을 사진을 여기 올립니다
```

한국어 문구는 `index.html`과 `news.html` 안에 직접 들어 있습니다.
영어와 헝가리어는 `i18n.js`에 모여 있습니다.

## 활동 기록에 새 소식 올리기

1. 사진을 `assets/news/` 폴더에 올립니다.
   파일 이름은 **영어와 숫자로만** 짓습니다. 예: `2026-09-15-meeting.jpg`
   한글 이름을 쓰면 사진이 안 뜹니다.

2. `news-data.js`를 열고, 맨 위 `var NEWS = [` 바로 아래에 아래 양식을 붙여넣습니다.

```js
  {
    date: "2026-09-15",
    place: "부다페스트",
    image: "assets/news/2026-09-15-meeting.jpg",
    link: "",
    ko: { title: "제목", body: "내용" },
    en: { title: "Title", body: "Body" },
    hu: { title: "Cím", body: "Szöveg" }
  },
```

3. 저장하고 GitHub에 올립니다. 1~2분 뒤 사이트에 반영됩니다.

### 주의할 점

- `date`는 반드시 `"2026-09-15"` 형태로 씁니다. 이 값으로 연도가 나뉘고 순서가 정해집니다.
- 영어·헝가리어를 비워두면 한국어가 그대로 나옵니다. 급하면 비워두고 나중에 채워도 됩니다.
- `image`를 `""`로 비워두면 사진 없이 글만 나옵니다.
- `link`를 비워두면 링크 버튼이 안 나옵니다.
- 각 `{ }` 묶음 끝의 **쉼표를 지우면 안 됩니다.** 맨 마지막 것만 쉼표가 없습니다.
- 쉼표나 중괄호를 잘못 지우면 활동 기록 페이지가 비어 보입니다. 그럴 땐 방금 넣은 부분을 지우고 다시 넣으세요.

## 문구 고치기

- 한국어: `index.html` 또는 `news.html`에서 해당 글자를 찾아 고칩니다.
- 영어·헝가리어: `i18n.js`에서 같은 이름(`heroTitle` 등)을 찾아 따옴표 안만 고칩니다.
- 태그(`<span ...>` 같은 것)와 `data-i18n="..."` 부분은 건드리지 마세요.

## 배포

GitHub Pages로 배포합니다. 저장소에 파일을 올린 뒤
Settings → Pages → Branch를 `main`으로 지정하면 공개됩니다.

도메인(`khbcc.org`)을 연결할 때는 이 파일들을 고칠 필요가 없습니다.
Settings → Pages → Custom domain에 주소를 넣고, 도메인 구매처의 DNS 설정만 바꾸면 됩니다.
